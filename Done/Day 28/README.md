## 💡 Data Structures – Prefix Sum, Difference Array, Pivot Index

### ✅ Prefix Sum
- Used to answer **range sum queries** in O(1) time.
- Implemented a prefix array for fast querying.

### ✅ Difference Array
- Used for **range updates** in O(1) time.
- Efficient for applying multiple updates over large arrays.

### ✅ Pivot Index
- Find the index where left sum = right sum.
- Optimized with running totals to achieve O(n) time complexity.

🛠️ All solutions implemented with clear, commented Python code.
