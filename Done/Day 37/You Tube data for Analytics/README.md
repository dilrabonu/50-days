
# 🎯 YouTube Title Performance Predictor & Coach

An intelligent AI assistant that helps YouTubers craft **viral video titles** by analyzing patterns in historical title performance using NLP and Machine Learning.

## 📁 Dataset

We worked with a curated dataset of over **600 YouTube video records**, containing:
- 🎬 **Titles**
- 🏷️ **Tags**
- 📊 **View counts, likes, dislikes**
- ⏱️ **Duration**
- 📆 **Published time & date**

The dataset was preprocessed, cleaned, and explored to extract powerful insights about what makes a YouTube title successful.

### 🔍 Key Insights Uncovered:
- Title length significantly influences click-through rate
- Including trending keywords improves discoverability
- Timing of publication can affect virality class

We used this data to engineer rich features for model training and future suggestions.

## 🔮 What We've Built So Far

✅ **Regression Model** to predict expected view count  
✅ **Classification Model** to estimate virality (Low / Medium / High)  
✅ **Title Embedding Pipeline** using DistilBERT  
✅ **Exploratory Visualizations** showing title success factors  
✅ **Helper Tools** for cleaning, embedding, and formatting
